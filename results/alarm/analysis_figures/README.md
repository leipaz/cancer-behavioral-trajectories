# Analysis figures (high resolution)

Delivery figures for the granularity summary and simplified patient trajectories.

| File | Content |
|------|---------|
| `summary_granularities_W90_H120.{png,svg,pdf}` | Metrics table (exact Youden operating points) + AUROC points with **patient-clustered bootstrap 95% CI** + ROC overlay (**no** winner star) |
| `metrics_table_W90_H120.csv` | Exact Sens/Spec/PPV/NPV/AUROC values shown in the table panel |
| `auc_ci_W90_H120.csv` | AUROC point estimates and 95% CIs |
| `trajectory_patient_62004_W90_simplified.*` | PD example: daily sliding pUF + daily/sampled burden vs monthly collapsed pUF/burden (mean scale) |
| `trajectory_patient_41006_W90_simplified.*` | No-PD example, same construction |

### Notes

- **AUROC CI:** patient-clustered bootstrap (resample patients with replacement; 2000 reps, seed=42).
- **Clinical clock:** **all** granularities in this figure use **`Obs_time`** (same field as the audited monthly baseline, n=1015). Sampled/collapsed pUF tables are aligned to `Subjects_data.Obs_time` before building decision points.
- **Monthly collapsed** landmarks come from `tables/decision_points_W3_H4.csv` (Obs_time clock, n=1015).
- **Trajectories:** thresholds are **construction-specific** Youden values on the **mean** scale (daily sampled vs monthly collapsed mean-equivalent), each labelled — not a shared validated cut-off. Progression day uses Obs_time.
- Raster exports at **400 dpi**.
- Regenerated by: `scripts/03_analysis/alarm/plot_analysis_figures.py`
