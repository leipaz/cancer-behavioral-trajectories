# Results

Outputs generated by scripts (figures, tables, saved models). Do not include raw patient data.

| Folder | Contents |
|--------|----------|
| `figures/` | Paper figures and supplementary material |
| `tables/` | Exported tables (CSV, LaTeX, etc.) |
| `models/` | Serialized models (`.rds`, `.pkl`, etc.) if saved for reproducibility |

Large or regenerable files may be excluded from git; in that case, document in the main README the command that regenerates them.
