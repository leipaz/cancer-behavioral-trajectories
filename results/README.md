# Resultados

Salidas generadas por los scripts (figuras, tablas, modelos guardados). No incluir datos crudos de pacientes.

| Carpeta | Contenido |
|---------|-----------|
| `figures/` | Figuras del paper y material suplementario |
| `tables/` | CSV/LaTeX de tablas exportadas |
| `models/` | Modelos serializados (`.rds`, `.pkl`, etc.) si se guardan para reproducibilidad |

Los archivos grandes o regenerables pueden excluirse de git; en ese caso documentar en el README principal el comando que los regenera.
