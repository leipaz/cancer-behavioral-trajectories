Usuarios del VQ-VAE original (no causal): entrenamiento y validación
Extracción: 2026-11-18

ARCHIVOS PARA LEIRE
usuarios_entrenamiento_postprocesado.csv: 1085 user distintos; 1099 filas.
usuarios_validacion_postprocesado.csv: 490 user distintos; 498 filas.

COLUMNAS
user: identificador original con el que el código separó usuarios entre particiones.
user_uid: segundo identificador original de la extracción eB2 de marzo de 2024.
service: código numérico original del servicio/cohorte. No se ha recodificado.
No se ha creado ni renombrado ninguna columna como user_id.

UNIDAD DE CADA FILA
Una combinación distinta (user, user_uid, service) presente en las observaciones
originales que sobrevivieron al procesamiento. Un user puede tener varias filas
si está asociado a distintos user_uid o servicios. Para recuperar los recuentos
1.085 y 490, contar valores distintos de user, no filas ni valores de user_uid.
No se han seleccionado IDs ni cohortes por mayoría ni se han eliminado relaciones.
Se excluyen las relaciones que solo aparecen en secuencias descartadas, aunque
otras secuencias del mismo user sí hayan sobrevivido.
